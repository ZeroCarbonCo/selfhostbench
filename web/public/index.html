Will it run well on my box?

SelfHostBench is a free, open-source script that measures how popular self-hosted apps actually perform on your home server. It starts each app in a temporary Docker container, runs the same fixed workload everyone runs, shows you the numbers, and — only if you say yes — adds them to a public results table, so the next person choosing a mini PC, NAS or single-board computer gets a measured answer instead of a guess.

What it tests (v0.1)

Ollama

Runs AI chat models locally. We measure how fast a small model (Llama 3.2 3B) writes text, in tokens per second.

Jellyfin

Personal media streaming. We measure how fast it converts a 4K video to 1080p, and how many people could stream at once.

Immich

Photo backup with AI search and face recognition. We measure how many photos per second it can index for search and faces.

Run it

Needs Linux (x86_64; arm64 such as Raspberry Pi 5 should work but is untested), Docker, Python 3 and about 15 GB of free disk. Takes roughly 10–40 minutes. Nothing is sent unless you approve the exact JSON at the end.

curl -fsSLO https://github.com/ZeroCarbonCo/selfhostbench/releases/download/v0.1.0/selfhostbench
curl -fsSLO https://github.com/ZeroCarbonCo/selfhostbench/releases/download/v0.1.0/selfhostbench.sha256
sha256sum -c selfhostbench.sha256
less selfhostbench          # read it first: ~800 lines of plain Python, standard library only
python3 selfhostbench

Prefer to keep results private? Add --no-submit. Test only some apps: --apps ollama,jellyfin. Details in the README.
